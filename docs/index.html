TurnDuration for Claude

Shows the response time under each answer in Claude Desktop: how long Claude took and when it finished.

The Claude Code CLI has this line built in; Claude Desktop does not, so this plugin draws it as a Claude Code mod.

Install

At the Claude Code terminal prompt:

/plugin install turn-duration --marketplace M1nu0x0/claude-turn-duration

Answer y to Add marketplace? and choose the user scope.

From a shell:

claude plugin install turn-duration --marketplace M1nu0x0/claude-turn-duration

In Claude Desktop, click + next to the prompt box → Plugins → Add marketplace, enter M1nu0x0/claude-turn-duration, then add turn-duration.

How it works

When the main turn ends, it prints a ✻ word for duration · done time line. Subagent turns and empty answers get no line.

Clock format

At session start it reads the OS's 12/24-hour setting and locale to format the time.

macOS
AppleICUForce24HourTime, AppleICUForce12HourTime and AppleLocale from defaults read -g
Windows
sShortTime and LocaleName under HKCU\Control Panel\International
Linux
The locale from LC_ALL, LC_TIME, then LANG; 12/24-hour from clock-format on a GNOME desktop.

Questions

Does the line show twice in the terminal?

The ✻ … for Ns line in the terminal is not from this mod; it is the TurnDuration line Claude Code draws on its own. The mod is blocked in code from adding a line in the terminal, so it never shows twice.

Where does it show?

Beneath answers on surfaces other than the terminal, such as Claude Desktop. Summary blocks are left as they are.

Does it send data anywhere?

No. At session start it only runs the commands that read the OS clock settings (defaults, reg, gsettings) on your own computer.

Which systems is it tested on?

CI runs on Ubuntu, Windows and macOS.

How do I remove it?

Run claude plugin uninstall turn-duration in a shell.

How do I see how long Claude took to answer in Claude Desktop?

Claude Desktop does not show it on its own. With this plugin installed, every answer gets a line such as ✻ Worked for 4s · done 1:15 PM beneath it, as the Claude Code CLI shows: the time the answer took and the time it finished.

Why does it say Churned, Crunched or Brewed?

The terminal picks a word for each answer, and a mod cannot read which one it picked, so this plugin picks one at random from its own list. The time and the clock are real.
