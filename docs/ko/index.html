TurnDuration for Claude

Claude Desktop 답변 아래에 응답 시간, 즉 Claude가 답하는 데 걸린 시간과 끝난 시각을 표시합니다.

Claude Code CLI에는 기본으로 있는 줄이지만 Claude Desktop에는 없어서, 이 플러그인이 Claude Code mod로 같은 줄을 그립니다.

설치

Claude Code 터미널 프롬프트에서:

/plugin install turn-duration --marketplace M1nu0x0/claude-turn-duration

Add marketplace?에 y를 누르고 scope는 user를 고릅니다.

셸에서는:

claude plugin install turn-duration --marketplace M1nu0x0/claude-turn-duration

Claude Desktop에서는 프롬프트 옆 + → Plugins → Add marketplace에 M1nu0x0/claude-turn-duration을 넣고 turn-duration을 추가합니다.

동작

메인 턴이 끝나면 ✻ 단어 for 시간 · done 시각 줄을 출력합니다. 서브에이전트 턴과 빈 답변에는 출력하지 않습니다.

시각 형식

세션이 시작될 때 OS의 12/24시간 설정과 로케일을 읽어 시각 형식을 맞춥니다.

macOS
defaults read -g의 AppleICUForce24HourTime, AppleICUForce12HourTime, AppleLocale
Windows
HKCU\Control Panel\International의 sShortTime, LocaleName
Linux
로케일은 LC_ALL, LC_TIME, LANG 순서로, 12/24시간은 GNOME 데스크톱에서 clock-format을 읽습니다.

자주 묻는 질문

터미널에서 줄이 두 번 보이지 않나요?

터미널에 보이는 ✻ … for Ns 줄은 이 mod가 아니라 Claude Code가 원래 그리는 TurnDuration 줄입니다. mod는 터미널에서는 줄을 더하지 않도록 코드에서 막혀 있어서 두 번 보이지 않습니다.

어디에서 보이나요?

터미널이 아닌 화면(Claude Desktop 등)에서 답변 아래에 그립니다. 요약 블록에는 붙이지 않습니다.

어디로 데이터를 보내나요?

보내지 않습니다. 세션이 시작될 때 OS의 시계 설정을 읽는 명령(defaults, reg, gsettings)만 내 컴퓨터에서 실행합니다.

어떤 OS에서 확인했나요?

Ubuntu, Windows, macOS에서 CI가 돕니다.

제거하려면 어떻게 하나요?

셸에서 claude plugin uninstall turn-duration을 실행합니다.

Claude Desktop에서 Claude가 답하는 데 걸린 시간을 보려면 어떻게 하나요?

Claude Desktop은 따로 보여 주지 않습니다. 이 플러그인을 설치하면 Claude Code CLI처럼 답변마다 아래에 ✻ Worked for 4s · done 13:15 같은 줄이 붙어, 걸린 시간과 끝난 시각을 보여 줍니다.

Churned, Crunched, Brewed 같은 단어는 뭔가요?

터미널은 답변마다 단어를 하나 고르는데, mod는 터미널이 고른 단어를 받을 수 없어서 이 플러그인은 자체 목록에서 무작위로 고릅니다. 시간과 시각은 실제 값입니다.
